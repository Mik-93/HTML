# HTML


**HTML (Hyper Text Markup Lengauge)** No es un lenguaje de programación. Es un lenguaje de marcado que ysa etiquetas para definir su estructura y el significado del contenido de una página.

Piensa eb HTML como en los planos de una casa. Los planos no son la casa en sí, pero definen dínde va cada pared, cada puerta o cada ventana. De la misma fotma, HTML no degfine colores, tamaños, ni animaciones; *define qué es cada elemento y cómo se relaciona con los demás.*

HTML  funciona con etiquetas **(tags)**. 
Cada etiqueta se escribe entre corchetes abgulares o los símbolosde mayor qué y menor qué `<>`, y la mayortía tiene una etiqueta de apertura y otra de cierre: 

```
<h1>Este es un título principal</h1>
<p>Este es un parrafo</p>
<a href= "https://google.com"> Este es un enlace </a>
```
## Atributos

Las etiquetas pueden tener atributos que agregan unformación adicional. En el ejemplo del enlace, `href` es un atributo que indica facia dónde dirige el enlace.


para cerrar una etiquieta, se necesita colocar otra etiqueeta, pero con la diferencia de que esta última tiene una diagonal.

Los enlaces requieren de "href" el cuál va en la etiqueta de apertura y por eso es que hay una etiqueta de cierre a mitad del escrito.
